# BraTS 缺失模态脑肿瘤分割项目状态

> 最后更新：2026-07-02  
> 当前阶段：已完成完整模态基线与四种单模态缺失压力测试；下一步开始 Modality Dropout baseline。

---

## 1. 项目目标

研究 BraTS 多模态 MRI 脑肿瘤分割在 MRI 模态缺失场景下的鲁棒性问题。

当前研究路线：

1. 完整模态 nnU-Net 基线；
2. 缺失模态直接推理压力测试；
3. Modality Dropout 鲁棒基线；
4. 模态—区域风险建模；
5. 风险校准伪标签与少标注训练；
6. 最终五折交叉验证和论文实验。

当前核心想法：

> 不同 MRI 模态缺失会对不同肿瘤区域产生不均匀的风险，因此缺失模态下的伪标签筛选和训练策略不应使用统一全局阈值。

---

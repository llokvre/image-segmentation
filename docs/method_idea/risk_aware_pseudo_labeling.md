# 风险感知伪标签：方法草案

> 状态：planned method。本文档描述动机、可实现形式和验证要求，不表示方法已经完成。

## 1. 动机

当前 Full-only 与 Modality Dropout 结果显示，风险由缺失模态和分割区域共同决定。例如 Missing T1c 下 ET/TC 的下降远大于 WT，Missing FLAIR 下 WT 的下降更突出。因此，缺失模态训练中的伪标签不应只使用一个对所有区域和缺失模式都相同的置信度阈值。

## 2. 风险矩阵

定义 `R(m, r)` 表示缺失模态 `m` 对区域 `r` 的风险。一个初始估计可以使用验证集上的 Dice drop 或 teacher-student disagreement，但正式实验中必须：

- 只使用训练内部信息估计风险；
- 在多折设置中避免验证标签泄漏；
- 对不同 fold 的风险矩阵做归一化和稳定性分析；
- 记录风险矩阵版本和估计数据范围。

当前结果只能提供先验动机，不能直接把测试集风险数值写入训练损失。

## 3. 伪标签过滤

给定缺失模式 `m`、区域 `r` 和 teacher 预测 `p_teacher`，拟使用两个条件：

```text
accept(x, r, m) = confidence(x, r) >= tau(m, r)
                  and uncertainty(x, r) <= kappa(m, r)
```

高风险区域可以使用更严格阈值，或者降低其伪监督权重。具体方向需要通过开发集选择，不能依据最终测试结果手工调节。

## 4. 区域级一致性

student 接受不同缺失模态输入，teacher 使用完整或弱扰动输入。对每个区域施加条件化一致性损失：

```text
L_consistency = sum_m sum_r w(m, r) * D(p_student(m, r), p_teacher(r))
```

`w(m, r)` 可以由可靠性和风险共同决定，但需要验证其是否会压低 ET 等小区域的学习信号。

## 5. 低标注方向

在 low-label setting 中，未标注病例可通过 teacher 产生候选伪标签；有标签病例用于校准风险矩阵和阈值。计划比较统一阈值、仅不确定性过滤、仅风险加权和二者结合。

## 6. 最小可行实现

第一版只实现区域自适应伪标签阈值，不同时引入所有组件。若该版本没有稳定改善，再分析是风险估计、阈值、teacher 质量还是 zero-fill 协议造成问题。
